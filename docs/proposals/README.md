# Proposals

Design proposals for Flexo MMS Layer 1 and the services built on it. A proposal describes the
problem, the intended behaviour, and how it maps onto the existing resource model; it is not a
commitment to implement.

| Proposal | Summary |
|---|---|
| [Memento datetime negotiation](memento-datetime-negotiation.md) | Read a branch as it was at a point in time (`Accept-Datetime`), commit graph/query routes, TimeMaps |
| [OSLC Configuration Management façade](oslc-config-management-facade.md) | Expose repos, branches, locks and collections as OSLC components, streams, baselines and global configurations; the Layer 1 primitives that requires |
